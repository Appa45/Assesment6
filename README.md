# Health And Fitness Tracker

A responsive React + Vite fitness dashboard with calorie tracking, weekly trends, an overall intake/burned pie chart, and recent records.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Features

- Add, edit, and delete daily health records.
- Persists records in browser `localStorage` under `healthAndFitness`.
- Weekly bar chart shows the current day and preceding six days only.
- Overall pie chart is visible even when there are no records.
- Responsive layout for desktop, tablet, and mobile.
